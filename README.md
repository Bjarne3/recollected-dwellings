# Threads of Memory

**Weaving Identity and Belonging** — an exhibition proposal for the course *Doing Modern and Contemporary Art: Curating as Practice in Art History* (University of Amsterdam, 2026), by Bjarne, Fiona, Lola and Marije.

The site is the visitor-facing website of the (fictional) touring exhibition and doubles as the group's pitch presentation.

## Presenting

Open the site and press **P** (or click **Present** in the top bar).

| Key | Action |
| --- | --- |
| → / Space / Page Down | Next slide (presentation clickers work) |
| ← / Page Up | Previous slide |
| N | Speaker notes |
| M | Back to the artist map |
| T | Switch light / dark |
| F | Full screen |
| Esc | Back to the website |

Adding `#present` to the address opens the site straight into presentation mode.
