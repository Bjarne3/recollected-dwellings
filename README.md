# Recollected Dwellings

An exhibition proposal for the course *Doing Modern and Contemporary Art: Curating as Practice in Art History* (University of Amsterdam, 2026), by Bjarne, Fiona, Lola and Marije.

Thirteen artists who work with recollection in thread, cloth and fibre; proposed first venue: TextielMuseum, Tilburg. The site is the visitor-facing website of the (fictional) touring exhibition and doubles as the group's presentation.

## Presenting

Open the site and press **P** (or click **Present** in the top bar).

| Key | Action |
| --- | --- |
| → / Space / Page Down | Next slide (presentation clickers work) |
| ← / Page Up | Previous slide |
| N | Speaker notes |
| M | Back to the artists overview |
| T | Switch light / dark |
| F | Full screen |
| Esc | Back to the website |

Adding `#present` to the address opens the site straight into presentation mode.

## Notes

This is not an exhibition of the TextielMuseum. Dates, tickets, shop, artist films and the Memory Archive are mock-ups; nothing is on sale. Artwork images are courtesy of the artists and their galleries and are used here for a student project only.
